API NEPTUN для розробників
NEPTUN надає відкритий, безкоштовний API з тими самими даними, що живлять нашу власну карту — жива стрічка повітряних загроз (БПЛА, ракети, КАБ) та офіційних тривог по Україні у реальному часі. Ви можете будувати власні карти й сервіси на цих даних. Достатньо однієї умови: зберігайте видиме посилання на NEPTUN (див. «Атрибуція та умови» нижче).
Що ви отримуєте
REST-снапшот — миттєвий стан усіх активних загроз і тривог однією GET-відповіддю (CORS відкритий, без ключів).
WebSocket-стрім — той самий живий потік подій, що й на нашій карті (snapshot → upsert/remove → heartbeat), у реальному часі, без опитування.
JS-SDK — та сама логіка, що й у нас: клієнт стріму + прогноз руху (dead-reckoning) міток між оновленнями. Один тег 
<script>.
Embed-віджет — вставте нашу карту цілком одним рядком.
Ключі API не потрібні. Сервіс безкоштовний і читальний (лише GET). Щоб усі споживачі не били по нашому origin, снапшот кешується CDN на кілька секунд — тому опитуйте REST не частіше ніж раз на 5 секунд, а для реального часу використовуйте WebSocket або SDK.
Швидкий старт (SDK)
Найпростіший шлях — підключити SDK і підписатися на живий потік. SDK містить той самий клієнт і 
predict(), що рухає мітки між оновленнями точно як у нас:
<script src="https://neptun.in.ua/sdk/neptun.js"></script>
<script>
  const client = new NEPTUN.RealtimeClient("https://neptun.in.ua");
  client.subscribe((snap) => {
    // snap.threats — масив активних загроз для вашої карти
    // snap.alerts / snap.alertOblasts — офіційні тривоги (райони / області)
    for (const t of snap.threats) {
      // dead-reckon: та сама логіка руху, що й на карті NEPTUN
      const p = NEPTUN.predict(t, Date.now());
      renderMarker(p.lat, p.lon, t.type, p.heading, NEPTUN.getTypeMeta(t.type));
    }
  });
  client.start(); // відкриває WebSocket (з REST-фолбеком та авто-реконектом)
</script>
Викликайте 
NEPTUN.predict(t, Date.now()) у вашому циклі анімації (напр. 
requestAnimationFrame), щоб мітки плавно рухалися за курсом між серверними оновленнями.
REST-ендпоінти
Базовий URL: 
https://neptun.in.ua. Усі відповіді — JSON, CORS 
*, лише метод 
GET.
GET /api/v1/threats
Поточний снапшот усіх активних загроз.
GET https://neptun.in.ua/api/v1/threats
{
  "serverTime": "2026-07-09T12:34:56.000Z",
  "threats": [
    {
      "id": "trk_1a2b",
      "type": "uav",                 // uav | recon | missile | ballistic | kab | mig31k | unknown
      "title": "Шахед",
      "region": "Одеська область",
      "district": "Одеський район",
      "locality": "Чорноморськ",
      "lat": 46.30, "lon": 30.65,
      "heading": 42,                 // курс у градусах (0 = північ), null якщо невідомо
      "confidenceLevel": "high",     // low | medium | high
      "sourceCount": 3,
      "count": 2,                    // розмір групи (нальоту), 0/відсутнє = не вказано
      "updatedAt": "2026-07-09T12:34:50.000Z",
      "status": "active",            // active | stale | resolved
      "explanationShort": "БпЛА курсом на Чорноморськ",
      "velocity": { "bearingDeg": 42, "speedKmh": 150 },   // якщо трек рухається
      "confirmedAt": "2026-07-09T12:34:20.000Z",           // якір dead-reckon
      "uncertaintyKm": 4,
      "positionQuality": "confirmed",
      "advisory": false,             // true = спостереження, а не сигнал ховатися (див. нижче)
      "areaOnly": false              // true = точки НЕМАЄ, названо лише область (див. нижче)
    }
  ]
}
advisory: true означає, що загроза — це спостереження, а не сигнал ховатися: факт зафіксовано, але широкої офіційної тривоги немає. Типовий випадок — зліт МіГ-31К над спокійною країною. Показуйте такі записи спокійно (без червоного, без сирени й без «ховайтеся»), інакше ваші користувачі привчаться ігнорувати сигнал, який справді має значення. Поле може бути відсутнє — це дорівнює 
false.
areaOnly: true означає, що точки немає: джерела назвали лише область («Ракета на Одеську область») і жодного населеного пункту чи району. Тоді 
lat/
lon — це центроїд області, тобто підпис посередині регіону, а не місце, про яке хтось повідомляв; 
region (і 
locality, що його повторює) несуть назву області, 
district порожній. Такий запис не можна малювати як місце: без екстраполяції руху, без курсу й без відстані «скільки кілометрів до мене» — інакше ви покажете людині вигадане число як факт. 
positionQuality тут завжди 
approx, а 
heading/
velocity/
trail завжди відсутні. Поле може бути відсутнє — це дорівнює 
false (звичайна точкова позначка).
GET /api/v1/alerts
Офіційні повітряні тривоги: райони та області (окуповані області — цілою).
GET https://neptun.in.ua/api/v1/alerts
{
  "raions":  [ { "key": "odeska:odeskyi", "name": "Одеський район", "oblast": "Одеська область", "since": "…" } ],
  "oblasts": [ { "key": "krymska", "name": "АР Крим", "oblast": "", "since": "…" } ]
}
Поле 
key збігається з ключем у raions.geojson (межі районів) та oblasts.geojson — ним ви підсвічуєте потрібні полігони на своїй карті без повторного геокодування.
GET /api/v1/messages
Жива стрічка повідомлень з Telegram-каналів (для інформаційної панелі).
GET https://neptun.in.ua/api/v1/messages
{ "messages": [ { "channel": "…", "text": "…", "date": "…" } ] }
WebSocket-стрім (реальний час)
Той самий потік, що живить нашу карту. Кожен фрейм — конверт 
{ type, ts, data }. Origin відкритий для будь-якого сайту.
const ws = new WebSocket("wss://neptun.in.ua/api/v1/stream");
ws.onmessage = (e) => {
  const env = JSON.parse(e.data);
  switch (env.type) {
    case "snapshot":  // { data: { threats: [...] } } — повний стан при підключенні
    case "upsert":    // { data: <Threat> }          — з'явився/оновився трек
    case "remove":    // { data: { id } }             — трек зник
    case "heartbeat": // keep-alive
    case "alerts":    // { data: { raions, oblasts } }
  }
};
Протокол детально: приклад REST-снапшоту. Рекомендуємо SDK (
RealtimeClient) — він уже робить валідацію фреймів, авто-реконект з backoff та REST-фолбек.
JS-SDK
Один самодостатній файл (~11 КБ), без залежностей. Дві збірки:
IIFE (глобальна 
NEPTUN): 
https://neptun.in.ua/sdk/neptun.js
ES-модуль: 
https://neptun.in.ua/sdk/neptun.esm.js
Контрольні суми збірки: 
https://neptun.in.ua/sdk/build-manifest.json — sha256 кожного файлу-джерела та кожної збірки.
Найкорисніше в API SDK:
new RealtimeClient(baseUrl) — 
.subscribe(fn) (одразу віддає снапшот, повертає функцію відписки), 
.start(), 
.stop(), 
.retry().
predict(threat, nowMs) → 
{ lat, lon, heading, flying } — dead-reckon позиції за курсом/швидкістю (та сама логіка, що й у нас).
getTypeMeta(type) — колір, назва, іконка та рівень серйозності типу загрози.
formatRelativeTime(iso), 
isStale(...), 
dest(lat, lon, bearing, km), 
distanceKm(...) та константи карти (
UKRAINE_CENTER, зум-рівні).
ES-модуль:
import { RealtimeClient, predict, getTypeMeta } from "https://neptun.in.ua/sdk/neptun.esm.js";
const client = new RealtimeClient("https://neptun.in.ua");
const unsub = client.subscribe((snap) => { /* … */ });
client.start();
Embed-віджет
Не хочете будувати власну карту? Вставте нашу цілком одним рядком. Адреса віджета — 
/embed/map: чиста карта без HUD, без панелей і без блоку підтримки.
<iframe
  src="https://neptun.in.ua/embed/map"
  style="width:100%;height:600px;border:0;border-radius:12px"
  title="Карта повітряних тривог України — NEPTUN"
  loading="lazy"
></iframe>
<p>Джерело: <a href="https://neptun.in.ua/">Карта повітряних тривог України — NEPTUN</a></p>
Мова інтерфейсу — 
?lang=uk|ru|en, наприклад 
https://neptun.in.ua/embed/map?lang=en.
Стара адреса 
https://neptun.in.ua/?embed=1 працює до 2027-02-01, після чого залишиться тільки 
/embed/map. Причина переходу — безпека ваших читачів: заголовок 
frame-ancestors дозволяє вбудовування за адресою, і поки віджетом була головна сторінка з параметром, вбудовувати доводилося дозволяти всю головну. Тепер вбудовується рівно карта. Якщо ви вже маєте 
?embed=1 на сайті — просто замініть рядок 
src, більше нічого робити не треба.
Атрибуція та умови
API безкоштовний і відкритий. Єдина обов’язкова умова — видиме посилання на NEPTUN поруч із картою/даними:
<a href="https://neptun.in.ua/">Дані: Карта повітряних тривог — NEPTUN</a>
Повні умови використання API (безкоштовно, лише читання, без гарантій, застереження щодо життєвої безпеки, чесне навантаження) — Умови використання API.
Важливо: NEPTUN — інформаційний агрегатор, а не офіційна система оповіщення. Дані можуть містити неточності або затримки. Якщо ваш сервіс стосується безпеки людей, чітко доносьте це до користувачів і завжди відсилайте до офіційних сигналів тривоги.
